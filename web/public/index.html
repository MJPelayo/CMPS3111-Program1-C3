Instructions

How to use the Language Recognizer

Enter a program sentence in the input box and select Validate Program. The C3 language recognizer will check whether your program follows the BNF grammar.

Valid Examples

begin SQR A1-C4 end begin TRI A1-C6-G3 end begin SQR A1-C4. TRI A1-C6-G3 end

Important Rules

  • Input is case-sensitive.
  • Spaces are significant.
  • Use exactly one space where the grammar requires a space.
  • Coordinates use a letter from A–G followed by a number from 1–6.
  • An SQR instruction requires two coordinates.
  • A TRI instruction requires three coordinates.
  • Multiple instructions are separated by a period (.).
  • A valid program must begin with begin and end with end.

Results

If the program is valid, the recognizer displays the rightmost derivation and parse tree. If the program is invalid, the recognizer displays the relevant validation errors.
